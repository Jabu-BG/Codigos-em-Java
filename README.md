# ☕ Estudos e Projetos em Java

Repositório dedicado ao meu aprendizado da linguagem **Java**, reunindo exercícios acadêmicos e projetos desenvolvidos durante minha graduação em Análise e Desenvolvimento de Sistemas.

## 📂 Organização

### Exercícios

- **Cadastro Simples:** aplicação com interface gráfica utilizando Java Swing.
- **Conta Bancária:** exercício de orientação a objetos, encapsulamento e manipulação de saldo.

### Projetos

- **Cadastro MVC:** aplicação que utiliza a separação entre Model, View e Controller.
- **DAO com SQLite:** exemplo de persistência de dados utilizando JDBC, Maven e operações CRUD.

## 🛠️ Tecnologias

Java • Swing • JDBC • SQLite • Maven

## 📚 Conceitos praticados

- Programação orientada a objetos
- Encapsulamento
- Interfaces gráficas
- Arquitetura MVC
- Padrão DAO
- Persistência em banco de dados
- Operações CRUD

## ▶️ Como executar

Os requisitos variam conforme o projeto.

Para o exemplo DAO, utilize JDK 17 ou superior e Maven 3.9 ou superior. Dentro da pasta do projeto:

```bash
mvn clean compile exec:java
```

Consulte os READMEs individuais para mais informações.
